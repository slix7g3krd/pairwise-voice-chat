# pairwise-voice-chat

组队语音里队友声音忽大忽小、电流麦、多人同时说话炸麦：VAD 阈值按固定 dB；混音按人数线性叠加；空间化用 2D 距离；噪声抑制在解码后；丢包隐藏只重复上一帧；采样率不同没重采样；讲话人优先级按加入顺序；回声消除参考信号用扬声器输出；静音检测和音乐声混；耳返延迟随缓冲变。audio/voice_chat.py 是核心，tests/test_voice_chat.py 15个红。要修的是：自适应 VAD；能量归一混音；3D 空间化；解码前降噪；PLC 插值；统一重采样；活跃度优先级；AEC 参考；语音/音乐分流；固定耳返延迟。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
